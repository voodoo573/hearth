# Hearth legal records

Short internal records that back up the public pages (`/privacy.html`, `/terms.html`, `/legal.html`). They are informed self-assessments, **not legal advice**. A solicitor should review them before you rely on them.

| File | What it is |
|---|---|
| `dpia.md` | Data protection impact assessment (UK GDPR Art. 35, light-touch) |
| `childrens-code-assessment.md` | Self-assessment against the ICO Age Appropriate Design Code's 15 standards |
| `online-safety-act.md` | Note on Online Safety Act 2023 scope, an illegal-content risk assessment and a children's access assessment |
| `data-safety-check.md` | Check that the Play data safety answers still match the app after the legal-fixes branch |

Review all four whenever you add a feature that sends data off the device, adds an SDK, or lets users share content with each other. Owner: Thomas Dalton. Next review: 11 April 2027.
