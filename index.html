Install Hearth
iPhone and iPad
  1. In Safari (or Chrome on iOS 16.4+), tap Share .
  2. Choose Add to Home Screen, then Add.
Android
  1. Tap Install Hearth, or open the browser menu ⋮.
  2. Choose Install app or Add to Home screen.
Computer
  1. Chrome or Edge: click Install Hearth or the install icon in the address bar.
  2. Safari on a Mac: File then Add to Dock.
  3. Firefox: can't install apps yet, so use Hearth in a tab.

About Hearth

Privacy

Your table, your device

No accounts, no tracking, no telemetry. Everything is stored in your browser and never leaves your device unless you export it. Privacy policy.

Honest warning

This is hobby software

Hearth is built by one person as a personal project, a single-file web app with no servers behind it. If you find a bug, it's a bug. You're an early reader of an unfinished book.

The leather-bound spellbook has been a fantasy ideal for fifty years. Hearth is what that ideal feels like when it has a battery.

Questions

Does it really work offline?

Yes. After the first load everything is on your device, so it works at a table with no signal.

Do I have to install it?

No. The website and the installed app run the same code. Installing adds an icon and a full-screen window.

How do I move characters to another device?

Export a backup file in the app and import it on the other device. Clearing browser data deletes your characters, so back up now and then.

Does it replace my DM or my dice?

No. Hearth does the bookkeeping. You roll the dice, and the DM makes the rulings.
