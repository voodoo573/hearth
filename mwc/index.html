Maximum Zs (Ω) — Table 41.3, 230 V

Measured Zs should be ≤ 0.8× these values (allows for conductor warming). Values derived U0×0.95 ÷ (trip multiple × In); Type B ×5, C ×10, D ×20.

RCDs

• Additional protection (30 mA): must trip ≤ 40 ms at 5×IΔn.
• Fault protection (ADS): Zs ≤ 50 ÷ IΔn — e.g. 30 mA → 1667 Ω, 100 mA → 500 Ω.
• General max ≤ 300 ms at 1×IΔn (BS EN 61008/61009).
• Always operate the test button.

Insulation resistance — Table 61

• SELV / PELV — test 250 V dc — min 0.5 MΩ
• Up to 500 V (incl. 230/400 V) — test 500 V dc — min 1.0 MΩ
• Over 500 V — test 1000 V dc — min 1.0 MΩ

Max disconnection times — Table 41.1, 230 V

• Final circuits ≤ 63 A: TN 0.4 s · TT 0.2 s
• Distribution & final > 63 A: TN 5 s · TT 1 s
Device magnetic trip: Type B ×3–5 · Type C ×5–10 · Type D ×10–20.
